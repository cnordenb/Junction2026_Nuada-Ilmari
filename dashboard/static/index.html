Swarm detector

Finds groups of posts or comments that are both similar in text and synchronised in time: the footprint of brigading, astroturfing and bot networks. It flags patterns for a person to review; it does not identify who is behind them.

1Choose a dataset

A CSV, TSV, JSON or JSON Lines file with one post per row. It needs a content column and a time-posted column.

Preview first rows

2Add sample posts (optional)

Paste posts you already find suspicious. The tool looks for posts like them in the dataset and checks whether they were posted in sync. Leave this empty to scan the whole dataset for swarms.

3Run the detection

Lower finds looser matches and more false alarms.
